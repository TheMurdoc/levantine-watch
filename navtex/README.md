# NAVTEX files

Optional second inbox for the NAVTEX layer (the main one is issues labelled `navtex`, see the main README).

- Put one or more raw messages in a `.txt` file here and push. Every `.txt` file in this folder is parsed as warnings and published in `data/live.json`.
- Delete the file (or add a `CANCEL` message) to withdraw a warning.
- Keep notes in `.md` files only.
